# Akademik to‘lqinlar — kunduzgi animatsion fon

Mavjud KPI ilovasi uchun yangilanish paketi. To‘liq dastur emas.

1. KPI dasturining qora oynasini yoping.
2. ZIPni alohida papkaga to‘liq oching (Extract All / Извлечь всё).
3. INSTALL-GALAXY.bat faylini ishga tushiring.
4. Mavjud KPI papkangizdagi start-native.bat faylini tanlang.
5. TAYYOR yozuvidan keyin start-native.bat orqali dasturni qayta oching.
6. Brauzerda Ctrl+F5 bosing va yuqoridagi quyosh tugmasi bilan kunduzgi rejimni yoqing.

Oq-moviy ishchi maydonda ko‘k va feruza to‘lqinlar ikki yo‘nalishda uzluksiz
harakatlanadi. Fon ilovaning ichida, kartalar va jadvallar orqasida qoladi.
Tungi galaktika ko‘rinishi saqlanadi. Internet yoki tashqi rasm kerak emas.
Operatsion tizimda harakatni kamaytirish yoqilganida to‘lqinlar statik ko‘rinadi.
Chop etishda bezaklar yashiriladi.

O‘rnatgich uchta interfeys faylini yangilaydi. Eski fayllar va standart SQLite
baza runtime/galaxy-backup-* papkasiga zaxiralanadi. Baza, parollar, dalillar
va HEMIS sozlamalari almashtirilmaydi.

Tekshiruv: haqiqiy CSS va rejim almashtirish JavaScript kodi bilan brauzer
maketida harakat, siklning uzluksizligi, 390/320 px mobil ekranlar,
tugmalar bosilishi, reduced-motion va chop etish tekshirildi.
ZIP va SHA256 tekshiruvlari o‘tdi. Windows BAT o‘rnatgichi va to‘liq PHP
ilovasi ushbu muhitda ishga tushirib tekshirilmagan.
