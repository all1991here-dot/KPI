# Sokin galaktika — tasdiqlangan 6-variant

1. KPI qora oynasini yoping.
2. ZIPni «Извлечь всё» bilan alohida papkaga oching.
3. INSTALL-GALAXY.bat ni oching va mavjud dasturingizdagi start-native.bat ni tanlang.
4. TAYYOR yozuvidan keyin start-native.bat ni qayta oching. Brauzerda Ctrl+F5 bosing.

Tizim ichida to‘q ko‘k fon, mayda yulduzlar, ko‘k-binafsha yorug‘lik va pastki sokin to‘lqin qo‘llanadi. Jadvallar, kartalar, maydonlar va bildirishnomalar tungi ranglarga mos. Dizayn barcha ichki sahifalarda ishlaydi. Yuqoridagi quyosh/oy tugmasi bilan och rejimga qaytish mumkin; tanlov shu brauzerda saqlanadi. Birinchi kirishda tasdiqlangan tungi variant ochiladi.

Fon CSS yordamida yaratilgan: tashqi rasm va doimiy animatsiya yuklanmaydi. Mobil ekran va chop etish moslashtirilgan. Kirish sahifasi, API kaliti, xodimlar va hujjatlar saqlanadi. O‘rnatgich o‘zgaradigan fayllarni va standart SQLite bazasini runtime/galaxy-backup-* ga zaxiralaydi.
